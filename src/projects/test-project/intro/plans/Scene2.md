## 0. 필수 원칙 (매 Scene 리마인드)
- **페르소나**: 뼈대는 Vercel처럼 정교하게, 질감은 펜 스케치처럼 따뜻하게.
- **레이아웃**: 구조적 깔끔함을 우선시하되, 뻔하지 않은 레이아웃 사용.
- **스케치 질감**: 펜 드로잉 부드러운 느낌으로 기획, Wobble 효과는 포인트로만 제한적 사용.
- **색상/폰트**: 임의 하드코딩 절대 금지. 반드시 theme.ts 토큰(COLORS.xx, FONTS.xx) 사용.
- **폰트 크기**: theme.ts의 SIZE_MD(48px)는 1920×1080 영상 기준 적절한 본문 크기. 임의 축소 금지.
- **한국어**: 고유명사·약어 외 모든 텍스트를 한국어로 작성.
- **자막 보호**: 하단 150px 영역에 핵심 요소 배치 금지.
- **이모지 금지**: 시스템 이모지(✅ 💡 등), 유치한 아이콘 절대 금지.
- **SVG 규칙**: SVG 내부에 `<text>` 태그 금지. 텍스트는 부모 Scene에서 HTML + theme 토큰으로.

## 1. 타임라인 및 텍스트 데이터 (수정 금지)
- 원본 텍스트: 사실 우리가 바쁜 이유는 능력이 부족해서가 아니라 도구가 없어서입니다.
- 타임라인: 128f 부터 시작 (총 165f 지속)
- 단어별 등장 프레임 (Local): { "사실": 0f, "우리가": 8f, "바쁜": 20f, "이유는": 28f, "능력이": 41f, "부족해서가": 54f, "아니라": 75f, "도구가": 94f, "없어서입니다.": 114f }

## 2. 디자인 및 연출 기획 (구현 전에 매우 자세하게 작성하세요, 반드시 값을 채워넣어야합니다.)
- 비주얼 컨셉: 이 장면은 '도구의 유무'가 바쁨의 원인이라는 메시지를 시각적으로 전달합니다. 텍스트는 이전 Scene과 유사하게 중앙에 배치하여 일관된 시각적 흐름을 유지하되, 핵심 키워드인 '도구'에 시각적 강조를 더할 것입니다. 전체적인 레이아웃은 구조적 깔끔함을 유지하면서도, 부드러운 펜 스케치 질감의 요소를 활용하여 메시지의 이해를 돕고 친근함을 더합니다.
- SVG 컨셉: 손으로 그린 듯한 연장(tool) 아이콘 SVG를 화면에 배치하여 '도구'라는 개념을 시각적으로 나타냅니다. 이 SVG는 간결한 선으로 이루어져 펜 스케치 질감을 살리며, 장면의 메시지를 은유적으로 보강하는 역할을 합니다. 복잡하지 않은 하나의 아이콘으로 시각적 집중도를 높입니다.
