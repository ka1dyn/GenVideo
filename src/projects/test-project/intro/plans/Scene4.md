## 0. 필수 원칙 (매 Scene 리마인드)
- **페르소나**: 뼈대는 Vercel처럼 정교하게, 질감은 펜 스케치처럼 따뜻하게.
- **레이아웃**: 구조적 깔끔함을 우선시하되, 뻔하지 않은 레이아웃 사용.
- **스케치 질감**: 펜 드로잉 부드러운 느낌으로 기획, Wobble 효과는 포인트로만 제한적 사용.
- **색상/폰트**: 임의 하드코딩 절대 금지. 반드시 theme.ts 토큰(COLORS.xx, FONTS.xx) 사용.
- **폰트 크기**: theme.ts의 SIZE_MD(48px)는 1920×1080 영상 기준 적절한 본문 크기. 임의 축소 금지.
- **한국어**: 고유명사·약어 외 모든 텍스트를 한국어로 작성.
- **자막 보호**: 하단 150px 영역에 핵심 요소 배치 금지.
- **이모지 금지**: 시스템 이모지(✅ 💡 등), 유치한 아이콘 절대 금지.
- **SVG 규칙**: SVG 내부에 `<text>` 태그 금지. 텍스트는 부모 Scene에서 HTML + theme 토큰으로.

## 1. 타임라인 및 텍스트 데이터 (수정 금지)
- 원본 텍스트: 첫 번째는 모든 기록을 자동화해 주는 스마트 노션 템플릿입니다.
- 타임라인: 452f 부터 시작 (총 123f 지속)
- 단어별 등장 프레임 (Local): { "첫": 0f, "번째는": 4f, "모든": 18f, "기록을": 27f, "자동화해": 40f, "주는": 69f, "스마트": 74f, "노션": 81f, "템플릿입니다.": 90f }

## 2. 디자인 및 연출 기획 (구현 전에 매우 자세하게 작성하세요, 반드시 값을 채워넣어야합니다.)
- 비주얼 컨셉: 이 장면은 '스마트 노션 템플릿'이라는 첫 번째 아이템을 소개하며, 자동화된 기록과 효율성을 시각적으로 강조합니다. 화면 중앙에 아이템의 핵심 기능과 관련된 간결한 텍스트를 배치하고, 주변에는 정돈되고 모던한 느낌의 요소를 활용하여 '노션'의 특징을 부각합니다. 펜 스케치 질감의 SVG와 깔끔한 레이아웃을 통해 전문적이면서도 사용자 친화적인 이미지를 전달합니다.
- SVG 컨셉: 손으로 그린 듯한 문서 아이콘 SVG를 화면에 배치하여 '노션 템플릿'을 상징적으로 나타냅니다. 문서 아이콘은 단순한 형태를 유지하되, 내부에 작은 자동화 관련 요소(예: 톱니바퀴나 화살표)를 펜 스케치 스타일로 추가하여 '스마트'와 '자동화'의 의미를 함축적으로 표현합니다. 이 SVG는 텍스트와 함께 배치되어 아이템의 특징을 직관적으로 보여줍니다.
