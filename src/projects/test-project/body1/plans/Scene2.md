## 0. 필수 원칙 (매 Scene 리마인드)
- **페르소나**: 뼈대는 Vercel처럼 정교하게, 질감은 펜 스케치처럼 따뜻하게.
- **레이아웃**: 구조적 깔끔함을 우선시하되, 뻔하지 않은 레이아웃 사용.
- **스케치 질감**: 펜 드로잉 부드러운 느낌으로 기획, Wobble 효과는 포인트로만 제한적 사용.
- **색상/폰트**: 임의 하드코딩 절대 금지. 반드시 theme.ts 토큰(COLORS.xx, FONTS.xx) 사용.
- **폰트 크기**: theme.ts의 SIZE_MD(48px)는 1920×1080 영상 기준 적절한 본문 크기. 임의 축소 금지.
- **한국어**: 고유명사·약어 외 모든 텍스트를 한국어로 작성.
- **자막 보호**: 하단 150px 영역에 핵심 요소 배치 금지.
- **이모지 금지**: 시스템 이모지(✅ 💡 등), 유치한 아이콘 절대 금지.
- **SVG 규칙**: SVG 내부에 `<text>` 태그 금지. 텍스트는 부모 Scene에서 HTML + theme 토큰으로.

## 1. 타임라인 및 텍스트 데이터 (수정 금지)
- 원본 텍스트: 두 번째는 집중력을 극대화하는 '뽀모도로 타이머' 활용법이에요.
- 타임라인: 118f 부터 시작 (총 145f 지속)
- 단어별 등장 프레임 (Local): { "두": 0f, "번째는": 6f, "집중력을": 22f, "극대화하는": 44f, "'뽀모도로": 71f, "타이머'": 93f, "활용법이에요.": 109f }

## 2. 디자인 및 연출 기획 (구현 전에 매우 자세하게 작성하세요, 반드시 값을 채워넣어야합니다.)
- 비주얼 컨셉: '뽀모도로 타이머'를 주제로, 화면 우측에 심플하고 세련된 원형 타이머가 서서히 채워지는 애니메이션을 배치합니다. 타이머 주변에는 집중력이 높아지는 상태를 시각화하기 위해 `COLORS.SECONDARY` 색상의 은은한 파동 효과(Ripple)를 적용합니다. 배경은 `COLORS.BG_BASE`를 유지하며, 좌측 상단에는 'Step 2'와 같은 레이블을 배치하여 구조적인 안정감을 줍니다.
- SVG 컨셉: 펜 스케치 느낌의 원형 타이머 프레임 SVG(`PomodoroTimer`)를 준비합니다. 내부의 채워지는 게이지는 SVG Path의 `stroke-dasharray`를 활용하거나, `DrawLine` 컴포넌트를 응용하여 스케치하듯 그려지는 느낌을 연출합니다. 텍스트 라벨(예: "집중 시간")은 Scene 레이어에서 `FONTS.SIZE_MD`와 `COLORS.TEXT_BODY`를 사용하여 타이머 하단에 배치합니다.
