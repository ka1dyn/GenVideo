## 0. 필수 원칙 (매 Scene 리마인드)
- **페르소나**: 뼈대는 Vercel처럼 정교하게, 질감은 펜 스케치처럼 따뜻하게.
- **레이아웃**: 구조적 깔끔함을 우선시하되, 뻔하지 않은 레이아웃 사용.
- **스케치 질감**: 펜 드로잉 부드러운 느낌으로 기획, Wobble 효과는 포인트로만 제한적 사용.
- **색상/폰트**: 임의 하드코딩 절대 금지. 반드시 theme.ts 토큰(COLORS.xx, FONTS.xx) 사용.
- **폰트 크기**: theme.ts의 SIZE_MD(48px)는 1920×1080 영상 기준 적절한 본문 크기. 임의 축소 금지.
- **한국어**: 고유명사·약어 외 모든 텍스트를 한국어로 작성.
- **자막 보호**: 하단 150px 영역에 핵심 요소 배치 금지.
- **이모지 금지**: 시스템 이모지(✅ 💡 등), 유치한 아이콘 절대 금지.
- **SVG 규칙**: SVG 내부에 `<text>` 태그 금지. 텍스트는 부모 Scene에서 HTML + theme 토큰으로.

## 1. 타임라인 및 텍스트 데이터 (수정 금지)
- 원본 텍스트: 머릿속 복잡한 생각들을 정리하는 것만으로도 뇌의 부하가 줄어들죠.
- 타임라인: 0f 부터 시작 (총 118f 지속)
- 단어별 등장 프레임 (Local): { "머릿속": 0f, "복잡한": 12f, "생각들을": 24f, "정리하는": 40f, "것만으로도": 56f, "뇌의": 80f, "부하가": 87f, "줄어들죠.": 100f }

## 2. 디자인 및 연출 기획 (구현 전에 매우 자세하게 작성하세요, 반드시 값을 채워넣어야합니다.)
- 비주얼 컨셉: 복잡한 머릿속을 시각화하기 위해 화면 중앙에 얽혀있는 선들이 나타나고, '정리하는 것'이라는 대사에 맞춰 선들이 정돈되어 깔끔한 직선이나 도형으로 변하는 애니메이션을 연출합니다. `COLORS.BG_BASE` 배경 위에 `STROKE_INK` 색상의 스케치 느낌의 선들이 대비를 이루도록 하며, 뇌의 부하가 줄어드는 느낌을 넉넉한 여백과 `COLORS.PRIMARY` 포인트 컬러를 통해 표현합니다. 전체적으로 Vercel 스타일의 정교한 그리드 레이아웃을 기반으로 하되, `Wobble` 효과를 적용한 손그림 요소로 따뜻함을 더합니다.
- SVG 컨셉: 복잡하게 꼬인 실타래 모양의 SVG(`TangledLines`)와 이를 정돈한 형태의 기하학적 도형(정사각형 또는 원) SVG(`CleanShape`)를 준비합니다. SVG 내부에는 텍스트를 일절 배제하고, 오직 펜으로 그린 듯한 질감의 패스(Path) 데이터만을 포함하여 `Wobble` 효과를 적용할 수 있도록 설계합니다. 텍스트 라벨이 필요한 경우 HTML 요소와 `FONTS.HANDWRITING` 또는 `FONTS.PRIMARY` 토큰을 사용하여 Scene 레이어에서 렌더링합니다.
