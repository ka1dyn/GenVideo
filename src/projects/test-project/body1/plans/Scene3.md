## 0. 필수 원칙 (매 Scene 리마인드)
- **페르소나**: 뼈대는 Vercel처럼 정교하게, 질감은 펜 스케치처럼 따뜻하게.
- **레이아웃**: 구조적 깔끔함을 우선시하되, 뻔하지 않은 레이아웃 사용.
- **스케치 질감**: 펜 드로잉 부드러운 느낌으로 기획, Wobble 효과는 포인트로만 제한적 사용.
- **색상/폰트**: 임의 하드코딩 절대 금지. 반드시 theme.ts 토큰(COLORS.xx, FONTS.xx) 사용.
- **폰트 크기**: theme.ts의 SIZE_MD(48px)는 1920×1080 영상 기준 적절한 본문 크기. 임의 축소 금지.
- **한국어**: 고유명사·약어 외 모든 텍스트를 한국어로 작성.
- **자막 보호**: 하단 150px 영역에 핵심 요소 배치 금지.
- **이모지 금지**: 시스템 이모지(✅ 💡 등), 유치한 아이콘 절대 금지.
- **SVG 규칙**: SVG 내부에 `<text>` 태그 금지. 텍스트는 부모 Scene에서 HTML + theme 토큰으로.

## 1. 타임라인 및 텍스트 데이터 (수정 금지)
- 원본 텍스트: 딱 25분만 몰입하고 5분 쉬는 규칙이 업무 속도를 두 배로 만듭니다.
- 타임라인: 263f 부터 시작 (총 156f 지속)
- 단어별 등장 프레임 (Local): { "딱": 0f, "25분만": 3f, "몰입하고": 31f, "5분": 49f, "쉬는": 60f, "규칙이": 71f, "업무": 87f, "속도를": 98f, "두": 114f, "배로": 120f, "만듭니다.": 132f }

## 2. 디자인 및 연출 기획 (구현 전에 매우 자세하게 작성하세요, 반드시 값을 채워넣어야합니다.)
- 비주얼 컨셉: '25분 몰입'과 '5분 휴식'의 대비를 시각화하기 위해 화면을 두 개의 영역으로 나눕니다. 왼쪽에는 `COLORS.PRIMARY`를 활용한 강렬한 몰입 상태를, 오른쪽에는 `COLORS.SECONDARY`를 활용한 편안한 휴식 상태를 상징하는 그래픽을 배치합니다. 두 영역 사이에는 `STROKE_INK` 색상의 수직 구분선을 스케치 느낌으로 그려 넣고, 업무 속도가 '두 배'로 올라가는 것을 화살표 애니메이션으로 강조합니다.
- SVG 컨셉: 몰입을 상징하는 번개 모양 SVG(`ConcentrationIcon`)와 휴식을 상징하는 커피잔 혹은 구름 모양 SVG(`RestIcon`)를 준비합니다. SVG는 최소한의 패스로 구성하여 `Wobble` 효과가 돋보이게 하며, 텍스트는 일체 포함하지 않습니다. 업무 효율을 상징하는 상승 화살표는 `DrawLine` 컴포넌트를 사용하여 역동적으로 그려지도록 구현합니다.
